Produce a supervisor for autonomous exploration of an unknown environment. The robot should explore continuously and efficiently, but it must prioritize collision avoidance. Do not allow move-forward behavior when an object is detected in front of the robot. Instead, obstacle-front events should send the robot into a safe turning or escape state, and the robot should only drive forward again after a clear-path condition is observed. The controller should remain deterministic, should not stall, and should maintain a sensible balance between exploration and caution.
