Create a finite-state exploration policy for a mobile robot that wanders through the world while avoiding collisions and actively covering space. The robot should move forward whenever the path ahead is clear; do not go forward when there is an object in front of it. If the front is blocked, transition immediately into a recovery behavior using clockwise rotation or counterclockwise rotation, and only use `full_rotate` if simpler turns are clearly insufficient. Return to forward movement promptly after `path_clear` becomes true. Keep the supervisor simple, deterministic, practical, and biased toward exploration rather than repeated scanning.
