Make a controller for a robot whose task is to reach the red area while avoiding the blue area. The robot should move safely through the bounded environment while avoiding obstacles. When blue_detected occurs, the robot should prioritize escape_blue to leave the blue danger area. When the blue area is not detected, the robot should use go_to_red as the main progress action toward the red area whenever it is safe. When red_detected occurs, the robot has reached the red area and should stop or hold position there.
