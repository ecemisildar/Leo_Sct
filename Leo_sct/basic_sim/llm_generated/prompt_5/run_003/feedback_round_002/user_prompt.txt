Make a controller for a robot whose normal behavior is to repeatedly drive in a square path, not to explore randomly. In clear space, the controller should cycle through four square sides: move_forward on side 1, turn 90 degrees using one consistent direction, move_forward on side 2, turn 90 degrees, move_forward on side 3, turn 90 degrees, move_forward on side 4, turn 90 degrees, then repeat from side 1. Use explicit states that remember the current side or corner of the square so the robot continues the square sequence after each action. Obstacle handling should be a temporary recovery behavior only: when an obstacle is detected, avoid it with a short safe turn or brief recovery action, then return to the square sequence.
