Make a controller for a robot whose task is to gather in the red area. The robot should move safely through the bounded environment while avoiding obstacles. When the red area has not been reached, the controller should use go_to_red as the main progress action whenever it is safe to do so. If an obstacle is detected, use short directed recovery actions and then return to go_to_red. When red_detected occurs, the robot has reached the red area and should stay there or use only minimal safe correction.
