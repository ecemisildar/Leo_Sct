Make a controller for a robot whose normal behavior is to repeatedly drive in a zigzag path, not to explore randomly. In clear space, the controller should alternate between short move_forward segments and turns that switch direction, for example move_forward, turn clockwise, move_forward, turn counterclockwise, then repeat. Use explicit states that remember whether the next turn should be clockwise or counterclockwise so the robot maintains the zigzag sequence after each action. Obstacle handling should be a temporary recovery behavior only: when an obstacle is detected, avoid it with a short safe turn or brief recovery action, then return to the zigzag sequence.
