Make a controller for a robot that moves around on its own and explores the area. The robot should spend most of its safe time making forward progress and covering new space rather than remaining in one place. Its movement should include occasional changes in direction so that it does not continue in the same direction for too long, but these adjustments should stay brief and should not interrupt exploration unnecessarily. When obstacles appear, it should avoid them carefully, recover efficiently, and return to exploration as soon as it is safe.
