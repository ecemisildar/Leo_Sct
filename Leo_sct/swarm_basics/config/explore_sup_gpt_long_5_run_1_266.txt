Build a safe exploration task description for a robot supervisor. The robot should navigate around the environment searching for free space and should keep making progress unless blocked. A front obstacle is a hard safety condition, so the supervisor must not enable forward motion while `obstacle_front` is active. Recovery from front obstacles should use a short backward move or turning actions, and recovery from side obstacles should encourage turning away from the obstacle. The resulting supervisor should be readable, deterministic, and suitable for real execution without unstable loops or conflicting choices.
