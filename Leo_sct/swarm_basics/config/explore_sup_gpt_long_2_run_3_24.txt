Create a finite-state exploration policy for a mobile robot that wanders through the world while avoiding collisions. The robot should move forward only when the path ahead is clear; do not go forward when there is an object in front of it. If the front is blocked, transition immediately into a recovery behavior using clockwise rotation, counterclockwise rotation, or a full rotate action, and only return to forward movement after `path_clear` becomes true. Keep the supervisor simple, deterministic, and practical so it does not deadlock or get trapped in repeated unsafe actions.
